# memEcho 路演版发布验收清单

使用方法：每项必须附可复现证据。未执行、只有口头确认、只在其他 commit 通过或依赖未授权外部环境的项目，均保持 `[ ]`。任何“发布阻断”项未完成时不得宣布路演版完成。

## A. 发布身份

- [ ] 发布版本已同步到 Tauri、Cargo 和 desktop package。
- [ ] 已记录 Git commit，工作树干净且依赖锁文件未漂移。
- [ ] 发布说明列明范围：Windows 11、单实例 SAE、无账号计费/云端长期记忆/自动更新。
- [ ] 未签名安装包已显著标注，不宣称正式可信发行。

证据：版本号、commit、`git status --short`、发布说明链接。

## B. 自动化质量门（发布阻断）

- [ ] `corepack pnpm typecheck` 通过。
- [ ] `corepack pnpm test` 通过。
- [ ] `corepack pnpm build` 通过。
- [ ] `python -m pytest services/gateway/tests -q` 通过。
- [ ] `cargo test --locked --manifest-path apps/desktop/src-tauri/Cargo.toml` 通过。
- [ ] OpenAPI/TypeScript 合同、状态枚举和 memEcho 1.1 结果无漂移。
- [ ] 测试输出不含未处理警告、秘密或 `HTMLCanvasElement.getContext` 噪声。

证据：带 commit、命令、退出码、通过数量和时间的完整日志。

## C. Docker 镜像（发布阻断）

- [ ] 从发布 commit 构建生产 target，构建上下文未包含秘密或开发缓存。
- [ ] 镜像不包含测试依赖、测试目录、`.env`、源码仓库元数据。
- [ ] 容器以 UID/GID `10001` 运行，非 root。
- [ ] `ReadonlyRootfs=true`、`CapDrop=ALL`、`no-new-privileges`。
- [ ] `/v1/health` 的容器健康检查变为 healthy。
- [ ] 缺少任一生产令牌/密钥时 Compose 配置失败。
- [ ] 镜像 history、inspect 和日志中不存在真实密钥。
- [ ] 镜像以不可变标签和 digest 推送到私有 ACR。

证据：构建日志、image digest、inspect 摘要、健康检查和秘密扫描结果。

## D. SAE / ALB / OSS（发布阻断）

- [ ] SAE 固定 1 个实例，端口 `8787`，存活/就绪路径为 `/v1/health`。
- [ ] 所有密钥通过保密配置注入，普通日志和变更记录不显示值。
- [ ] ALB 仅暴露 HTTPS `443`，证书有效，后端 `8787` 不直接公开。
- [ ] HTTPS、WSS 和 SSE 均通过真实桌面客户端验证。
- [ ] 心跳短于 ALB 空闲超时，断线后桌面端继续本地录音并可恢复。
- [ ] OSS Bucket 私有、禁止公共读、最小权限限制到临时前缀。
- [ ] 应用成功、失败、取消三条路径都立即删除 OSS 对象。
- [ ] OSS 当前版本、历史版本、删除标记和未完成分片配置 1 天清理兜底。
- [ ] 回滚到上一 digest 的流程已演练；明确回滚不恢复进程内会话。

证据：脱敏配置截图、网络测试记录、OSS 对象审计和回滚记录。

## E. Windows MSI / NSIS（发布阻断）

- [ ] 同一发布 commit 生成 MSI 与 NSIS。
- [ ] 两个文件均记录 SHA-256、大小、构建时间和签名状态。
- [ ] MSI 在干净 Windows 11 x64 完成安装、首次启动、重启和卸载。
- [ ] NSIS 在干净 Windows 11 x64 完成当前用户/全局安装选择、启动和卸载。
- [ ] WebView2 可用；离线会场已验证对应安装策略。
- [ ] 安装目录、日志和安装包内容不含百炼/OSS/网关密钥。
- [ ] 拒绝录音权限时错误可恢复，不崩溃、不生成伪音频。

证据：虚拟机快照、安装录屏、事件日志、产物清单和校验和。

## F. 端到端产品闭环（发布阻断）

- [ ] 麦克风与 WASAPI 系统回环分别生成可播放的 WAV。
- [ ] 暂停期间不写音频，恢复后双轨时间线受控。
- [ ] 异常退出后可发现并恢复录音清单。
- [ ] 实时字幕约 3 秒出现并明确标注临时；断网不丢本地录音。
- [ ] 8 MiB 分块、SHA-256、重复分块、断点续传和重复 complete 通过。
- [ ] 多人录音停在 `awaiting_identity`，用户确认“我”后同一任务继续。
- [ ] Fun-ASR、文件情绪和 DSP 对齐；质量不足时声学权重诚实降级到 `1/0`。
- [ ] 报告含纪要、共识、分歧、确认/建议 TODO、事实/观点/态度、VAD、自我回声、证据和不确定性。
- [ ] 每项重要结论引用证据 ID/时间戳，区分 observed/computed/interpreted。
- [ ] 不出现心理诊断、隐藏意图判断、声纹身份推断或仅按先后推因果。
- [ ] JSON、Markdown、独立 HTML 和 SQLite 记录一致且可重复保存。
- [ ] 证据回听跳转到正确本地音频时间段。
- [ ] 继续互动只携带用户显式选择的单次报告/证据上下文。
- [ ] 删除会话同步删除音频、报告和来源于该会话的派生记忆。
- [ ] 任一模型失败时显示降级/重试状态，不展示臆测结果或硬编码 demo 数据。

证据：3–5 分钟授权的单人、多人、无声、噪声和断网样例记录。

## G. 视觉与无障碍

- [ ] 球体的空闲、录音、暂停、分析、回应、记忆状态可区分且不过度跳动。
- [ ] 录音反馈为呼吸式波面扩散，不出现小圆点粒子。
- [ ] 实际音量驱动录音起伏，暂停和 reduced-motion 时正确收束。
- [ ] WebGL 不可用时 Canvas/CSS 降级，核心录音操作仍可用。
- [ ] 键盘、焦点、屏幕阅读器标签、对比度和缩放通过人工验收。

证据：自动化测试、截图/录屏、系统 reduced-motion 与禁用 WebGL 复验。

## H. 隐私与现场准备（发布阻断）

- [ ] 路演样例已获授权并完成脱敏，不含可识别真实个人的信息。
- [ ] 客户端、网关、SAE、ALB、OSS 日志不记录媒体、逐字稿、姓名、报告正文或凭据。
- [ ] 桌面 token 仅存 Windows Credential Manager。
- [ ] 删除会话后检查本地文件、SQLite、派生记忆和 OSS 均无残留。
- [ ] 已准备网络中断、百炼故障、OSS 故障和未识别说话人的现场降级话术。
- [ ] 现场前完成凭据有效期、额度、地域、模型权限、证书到期和磁盘空间检查。

证据：秘密扫描、删除审计、故障演练记录和路演前检查签字。

## 当前必须由外部环境补证的项目

本清单落库不等于以下项目已完成：

- Docker daemon 上的真实镜像构建、运行、健康检查和 inspect。
- 阿里云 ACR/SAE/ALB/OSS 的真实配置与回滚演练。
- 使用有效百炼/OSS 凭据的付费烟雾测试。
- Windows 11 干净虚拟机上的 MSI/NSIS 生成、安装、录音、卸载。
- 授权音频、真实麦克风与系统回环设备的端到端验证。
