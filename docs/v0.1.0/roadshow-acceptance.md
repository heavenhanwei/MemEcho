# memEcho Windows 路演版验收矩阵

本文档是路演版完成判定的唯一清单之一。单元测试通过不能替代端到端或真实设备验证；每项只有在“证据”列可以复现时才标记完成。

## 自动化质量门

| 范围 | 验证命令 | 完成条件 | 当前状态 |
|---|---|---|---|
| 前端类型 | `pnpm --filter @memecho/desktop typecheck` | 无 TypeScript 错误 | 基线通过，待集成后复验 |
| 前端行为 | `pnpm --filter @memecho/desktop test` | 录音状态机、身份确认、失败重试、Web 降级、reduced-motion 全部通过 | 部分覆盖，待补齐 |
| 前端构建 | `pnpm --filter @memecho/desktop build` | 生产构建成功 | 基线通过，待集成后复验 |
| 网关 | `python -m pytest services/gateway/tests -q` | 百炼适配、上传幂等、身份确认、OSS 清理、合同校验全部通过 | 基线通过，待集成后复验 |
| Windows 原生层 | `cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml` | WASAPI、恢复、上传、报告落盘全部通过 | 分支通过，待合入后复验 |
| 合同 | 前后端 OpenAPI/TypeScript 合同检查 | 请求、响应、状态枚举和 memEcho 1.1 结果无漂移 | 待实现 |
| 安全 | 静态配置与日志检查 | 无密钥、逐字稿、姓名、报告正文日志；无宽泛文件权限 | 待复验 |

## 端到端场景

| 场景 | 操作与预期 | 证据 | 当前状态 |
|---|---|---|---|
| 双轨录音 | Windows 11 选择麦克风与系统输出，分别生成可播放的 `mic.wav`、`loopback.wav` | 授权测试设备录音与 WAV 元数据 | 基础能力完成，待真实设备复验 |
| 暂停恢复 | 暂停期间不写入音频；恢复后时间轴连续且双轨偏移受控 | Rust 测试与授权录音 | 基线测试通过 |
| 异常恢复 | 录音中强制退出，重启后发现并恢复会话 | 恢复清单、恢复后的可播放音频 | 基线测试通过，待 UI 复验 |
| 实时字幕 | 正常网络下首段临时字幕约 3 秒出现，明确标注“临时” | 带时间戳屏幕记录 | 待真实百炼联调 |
| 网络中断 | 实时连接断开时继续本地录音；结束后可补做完整转写 | 断网测试记录、最终报告 | 待实现与验证 |
| 分块续传 | 8 MiB 分块、SHA-256 校验；重复分块和重复完成不破坏结果 | 网关 + Rust 合同测试 | 开发中 |
| 说话人确认 | 多人录音暂停在 `awaiting_identity`；用户确认“我”后同一任务继续 | API/UI 集成测试 | 开发中 |
| 会后分析 | Fun-ASR、文件情绪与本地 DSP 对齐；质量不足时降低或取消声学权重 | 脱敏样例报告与模型清单 | 部分完成，待真实联调 |
| 结果合同 | 每项重要结论具有证据 ID/时间戳、置信度、替代解释和 observed/computed/interpreted 来源 | memEcho 1.1 校验结果 | 合同已有，待真实输出复验 |
| 自我回声 | 指定“我”后显示其话术对不同参与者 VAD 的表达层影响，不推断隐藏意图 | 脱敏多人样例报告 | 待端到端验证 |
| 证据回听 | 从报告结论跳转并播放对应本地音频时间段 | UI 自动化 + 人工回听 | 待实现 |
| 继续互动 | 只携带用户选中的报告/证据片段，SSE 流式回答 | API/UI 集成测试 | 基础接口完成，待上下文选择复验 |
| 本地保存 | JSON、Markdown、独立 HTML 与 SQLite 记录一致，可重复保存 | Rust 测试、文件检查 | 开发中 |
| 会话删除 | 删除会话同步删除音频、报告及来源于该会话的派生记忆 | 数据库/文件系统集成测试 | 部分完成，待派生记忆覆盖 |
| 关系记忆 | 只显示用户确认的记忆；点/面可回到来源，来源删除后失效 | 多会话 UI 测试 | 待实现 |
| 导入 | MP3/WAV/M4A/MP4 和文本可创建会话并进入同一分析流程 | 导入样例测试 | 待实现 |

## 完成判定

只有当上述所有纳入本轮范围的项目具有可复现证据，且不存在未说明的模拟结果、声学臆测、心理诊断或云端媒体残留时，才可将路演版标记为完成。账号、计费、多设备同步、自动更新、代码签名和正式商店发布不属于本轮。
